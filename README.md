# GT7 TRACE 
TRACE - Telemetry Racing Analytics & Comparative Engine 
 
GT7 live telemetry dashboard and lap analysis tool. 
 
## Files 
- gt7telem.py - Live telemetry dashboard 
- lap_analyst.py - 14-chart lap analysis tool 
- gt7udp.py - UDP receive + Salsa20 decryption 
- config.py - Configuration (set your PS IP here)
