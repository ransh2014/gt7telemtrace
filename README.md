# gt7telem (TRACE)

GT7 telemetry capture, live dashboard, and lap/race analysis toolkit.

## Install (dev)

```
pip install -e .
```

## Run

```
gt7telem
```

Opens the TRACE menu: Live Dashboard, Lap Analyst, Race Analyst.
Make sure GT7 is running on your PS4/PS5 and enter its IP in the
Dashboard field before connecting.

Recorded laps are saved in a `laps` folder next to wherever you run it from.
